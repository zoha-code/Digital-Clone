My Project Write-up: What I Built and What I Learned

Introduction

I am Zoha Shafique, a 7th semester BS Software Engineering student. This document is a long-form write-up of the academic projects I have worked on during my degree. I do not only want to list the project names. I also want to explain what each project was about, which area of computer science it belongs to, and what I learned from building it. My projects cover machine learning, web development, assembly language coursework, and software requirements engineering.

Project 1: Smart AI Detection System

The Smart AI Detection System is my machine learning project. It belongs to the domain of Machine Learning, and its goal was to apply machine learning concepts to build an intelligent detection solution. This was the project where I understood how a machine learning workflow actually runs in practice, instead of only reading about it in lectures. Working on it gave me practical exposure to AI implementation. It is also one of the projects that increased my interest in Artificial Intelligence and Machine Learning, especially in how they can solve real-world problems.

Project 2: E-Commerce System

The E-Commerce System is my web development project. I built it as a university project, and it focused on the basic functionality and structure of an online shopping platform. Through this project I learned how an online shopping system is organized and how the different parts of a web application connect with each other. It gave me a first practical understanding of web development concepts. It was an academic project, so it was focused on learning the structure and basic features rather than being a full commercial platform.

Project 3: Book Management System

The Book Management System was part of my Computer Organization and Assembly Language (COAL) coursework. The project focused on managing book-related information through a software-based solution. Assembly language is quite different from the high-level languages I normally use, such as Python and Java, so this project pushed me to think more carefully about how a program actually works. It gave me practical exposure to implementing academic concepts inside a real project.

Project 4: Plagiarism Detection System

The Plagiarism Detection System was developed for my Software Requirements Engineering (SRE) course. The system focuses on identifying similarities between text documents. For this project I worked with text processing techniques and similarity-based approaches. This project helped me understand how software requirements are translated into a working application. In requirements engineering it is easy to stay at the level of documents and diagrams, but here I saw how a requirement becomes something that actually runs. It also connects to my interest in Natural Language Processing.

How I Approach Projects

Across all four projects, I follow a similar approach. I prefer step-by-step learning with practical implementation. When a technical concept is difficult, I break it into smaller parts and understand each part through examples and practice. I believe that understanding a concept is more important than memorizing it, and building a project is the best way for me to check whether I really understood something.

Tools and Skills Used in My Learning

During my degree I have worked with Python, Java and SQL. I have also used tools such as Visual Studio Code, Google Colab, Jupyter Notebook, Git and GitHub, and Android Studio. My studies and projects have touched machine learning, databases such as MySQL, web development, and software testing.

Connection With My Internship

My projects also connect with my internship at Big Brains, where I worked on software quality engineering. During the internship I tested an Android learning application, prepared and executed test cases, explored authentication testing, and gained basic exposure to application security testing through tools such as OWASP ZAP and Burp Suite. Building projects taught me how software is created, while the internship taught me how software is tested and how quality is checked. Together they give me a more complete view of software engineering.

What These Projects Taught Me

Working on different academic projects helped me explore multiple areas of software engineering. I gained practical exposure to problem-solving, programming, software design, and implementing technical concepts. I enjoy projects that let me learn new technologies and build solutions to real-world problems.

What I Want to Build Next

My goal is to strengthen my technical foundation, gain more industry experience, and work on meaningful technology-based projects. I am especially interested in continuing to work in Artificial Intelligence and Machine Learning, and in improving my practical skills with modern software development tools.
